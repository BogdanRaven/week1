# Results

This directory contains the normalized benchmark records used by the model-selection guide. The prompts are preserved in `exercises/`, while the longer narrative evaluations remain in `homework_part1.md`, `homework_part2.md`, `homework_part3.md`, and `homework_part5.md`.

The result tables record measured response/token values where available and the feature-level observations used for the qualitative ratings. Hidden system/tool tokens were not available, and the security/API snippets were reviewed statically rather than run against external services.
